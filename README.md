📱 Hungry Hub — Мобилно приложение
> Android приложение за поръчка на храна, изградено с .NET MAUI.
---
🙋 За кого е?
Приложението е предназначено за обикновени потребители — хора, които искат да разгледат ресторанти и да поръчат храна директно от телефона си.
---
✨ Какво може да прави потребителят?

👤 Профил — регистрация, вход и редактиране на личните данни и снимка

🍽️ Ресторанти — разглеждане на наличните ресторанти и техните менюта

🛒 Поръчка — избиране на ястия и подаване на поръчка

📦 Проследяване — следене на статуса на поръчката в реално време

---
🛠️ Технологии
	
Платформа	.NET MAUI (Android)
Архитектура	MVVM
Комуникация	REST API (Django backend)
Автентикация	JWT с автоматичен refresh
